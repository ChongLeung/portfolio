# Portfolio presentation

Alex Harbour is a fictional creative-developer persona. Pocket Garden, City Notes and Quiet Desk are fictional design concepts, not client work, deployed services, or evidence of professional experience. The introduction, project labels, and About page make that distinction visible.

Each card opens its own idea and approach text without navigating to an invented URL. One-thing mode keeps one concept open and uses a single-column layout. The sole external content action points to the real owner profile.

Controls use the locally installed official `@material/web` package. Artwork is locally authored abstract SVG, explicitly described as static illustration. All assets needed for this initial presentation are local. There are no remote fonts, analytics scripts, stock portraits, or contact forms.

The layout supports narrow viewports with stacked cards and wrapping header actions. Development-preview checks found and repaired global reset interference with component padding and header overflow at 320 px. A complete source-bound production matrix is still pending.
